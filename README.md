# Funniest Time Machine Warning Label

A one-line warning label for a time machine, written like a genuine safety
notice. It turns the grandfather paradox into a bureaucratic warranty clause
whose list of voided items escalates — warranty, birth certificate, and
finally the reader — saving the surprise for the last word.

The label (93 characters):

> WARNING: Tampering with your grandfather voids the warranty, your birth certificate, and you.

## How to run

```sh
python3 main.py
```

This writes the label to `/output/entry.txt` (creating the directory if
needed), using only the Python standard library.
